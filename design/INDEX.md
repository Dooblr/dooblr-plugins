# dooblr design index (read this first)

Agents: start here instead of crawling the repo.

1. Read this file, then the plugin's file in `design/plugins/`. Its generated map lists the
   version, every parameter (id, range, default), each source file with a one-line role, the
   UI components and window sizes, the tests, and how to build and install.
2. Open only the source files the map points you to.
3. Suite-wide visual and engineering rules: `design/dooblr-design-system.md` (tokens in
   `design/dooblr-design-tokens.json`).
4. Staleness: each map records the folder's git tree hash. If
   `git rev-parse --short=12 HEAD:<plugin>` differs, run `python3 design/tools/update-design.py <plugin>`.

The tables below and the generated maps are rewritten automatically (pre-commit hook in
`.githooks/`, and the `design-maps` GitHub workflow on pushes to main). Hand-written notes
outside the markers are never touched; keep them current with any behaviour change.
