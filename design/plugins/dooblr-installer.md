  distressor, 0coast, generate, sub, chords, titan. New since 0.1.4: **dooblr-0coast**,
  **dooblr-generate**, **dooblr-sub** (generate existed in the repo but had no installer entry).
  dooblr-generate is Mac-only in the release: the zip is the VST3 plus the embedded worker
  `.py`; model weights and the Python runtime are never bundled. Windows packaging skips it.
