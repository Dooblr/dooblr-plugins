## Notes (hand-written)

- Suite-wide rules: `design/dooblr-design-system.md` (sections 1-10 and 12).
- `dooblr-titan/README.md`
- MIDI effect, not a processor of the live input: the track's MIDI still passes through. Work
  happens on a loaded clip (file drop or USE CLIP) and is written to a **new** Session slot.
- Live 11 cannot drop Session/Arrangement clips onto `live.drop`. USE CLIP is the Live-clip
  fallback (`detail_clip`, then `highlighted_clip_slot clip`). Save MIDI is the file export
  path; Max 8 `live.drop` has no drag-out.
- Piano roll and variation list are graphs: **no hint captions**. Empty roll is an empty grid.
- Groove-preserving quantize: median micro-offset of inliers (within 1/4 of the grid), then
  lerp toward (grid + swing + that offset) by Q Str. Outliers are pulled onto the groove.
- Variations are four named characters (Displace, Substitute, Fill, Invert), scaled by Amount
  × type dials, deterministic per seed. Amount 0 is a no-op.
- Auto Key applies only when a source is loaded, and only if Auto is on. It does not fight a
  Root/Mode change the user makes afterwards.
- Dimmed, not hidden: Grid/Swing/Groove when Q Str is 0; Gap when Legato is off; VelMin/VelMax
  when Comp and Human are both 0. Root/Mode/Auto stay fully visible: variations always use the
  key, and Auto Key runs on load even if Snap is off.
