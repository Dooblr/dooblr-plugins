## Notes (hand-written)

- Suite-wide rules: `design/dooblr-design-system.md` (sections 1–10). Layout is a one-page
  hardware-style board (ratio row, detector / audio modes, four main knobs, headroom / mix /
  meters), drawn with the existing palette only. No new colour, font, radius or alpha tokens.
- `dooblr-distressor/README.md`
- This is an **independently designed approximation** of the Empirical Labs EL8 Distressor,
  from the EL8X manual and the Universal Audio EL8 manual. It is not a circuit-level emulation
  and does not use third-party code, artwork or trademarks on the UI.
- **British Mode** is omitted: neither manual documents it.
- **Power** is omitted: Bypass is the real in/out (and keeps GR metering alive, as UA describes).
- **Yellow distortion LED = 1 % THD**, as UA specifies. The EL8X PDF contradicts itself
  (features list: "1% LED"; distortion-modes page: yellow LED at 0.25 % THD). Documented in
  the README; the DSP threshold is `dsp::DistressorEngine::thdLed1` (0.01).
- **Mono + Link** models the hardware dead patch: the detector is halved because the missing
  second unit contributes silence, so there is less GR and the saturators run hotter.
- Input knob 5 is 0 dB into the nonlinear input stage; each knob unit is 3 dB. Input also
  lowers the effective threshold (1.2 dB per knob unit above 5). Output knob 5 is 0 dB after
  the output stage. Headroom 16 dB is unity internal drive; higher Headroom *values* push harder.
- 2:1 / 3:1 / 4:1 minimum attack is 20 µs; every other ratio is 50 µs. 10:1 opto release can
  stretch to 20 s after a long sustain. Nuke release is logarithmic in remaining GR.
- Mix is zero-latency and phase-aligned: Mix 0 is a bit copy of the input; wet and dry peak
  on the same sample when Audio HP is off.
