## Notes (hand-written)

- Suite-wide rules: `design/dooblr-design-system.md`. User docs: `dooblr-rhythm/README.md`.
- **What it is**: a VST3 instrument that generates a cohesive Latin / African / Afro-house /
  Afrobeat / world-electronic percussion *ensemble*. Parts have roles (timekeeper, clave/key,
  bass anchor, interlocking mid, lead/solo) and are placed relative to each other, not as
  independent random sequences.
- **One-click generate**: Style, host BPM, time signature and length (1–16 bars) produce a
  full arrangement. Variation = seed+1 with locks held. Regen = a new random seed with locks
  held. Generate is a large accent button, not a parameter.
- **Clave / key**: son and rumba 3-2 / 2-3 over two 4/4 bars; 6/8 bell and 5-stroke 6/8 clave
  on a 12-step grid; partido alto for samba/baile. Key strokes are structural 2 and are never
  dropped, swung or push/pulled. Tumbao open tones are constrained to clave-consistent steps
  (4, 4&, and the 3-side bombo).
- **Masking**: at most two onsets in the same register on the same step; extras shift to a
  free neighbour or are dropped. Clave and bass win.
- **Sound**: built-in kit is modal + filtered-noise synthesis. Round-robin randomises modal
  tuning, strike position (mode mix) and the noise seed. No third-party samples, logos or
  branding are bundled. User WAVs per instrument/articulation bucket are optional and stored
  as paths in the session.
- **Realtime**: generation and sample loads run on the message thread. `PatternSlot` /
  `SampleSlot` publish with the Dekker-style acquire used in dooblr-generate. `processBlock`
  does not allocate or take locks. Host playhead (BPM, ppq, isPlaying) clocks the grid;
  preview Play self-clocks when the host is stopped. C2 toggles preview; the C1-up map
  triggers instruments.
- **UI**: one page, 940×600 / 1080×660 / 2400×1400. Header (title, version `componentID`
  `version`, Undo/Redo, presets, Output, meter). Arrange + Generate + host BPM. Groove macros.
  Instrument grid (mute/solo/lock + editable steps with articulation glyphs and playhead).
  Selected-instrument ControlPanel. Drag MIDI (whole arrangement) / drag a sequencer row
  (that instrument) / Drag WAV / Load WAV. No hint text on the grid.
  Existing palette, ControlPanel, OutputMeter and undo history; no new colour, font, radius
  or alpha tokens.
  Header inset is 32 px (same as dooblr-m / throat). The stereo output meter is 34 px
  wide with 10 px to the Output slider, so it is not a 20 px sliver on the window edge.
  Generate sits in a 200–248 px hero column; Variation gets at least 112 px (5/8 of that
  row) so the label is not flush with the button edges.
- **Linux (this environment)**: `DooblrRhythmTests` 12/12 passed including clave, tumbao,
  stacking, monotonic density/complexity/syncopation, pattern lock, fills, seed, MIDI
  round-trip, state round-trip, processBlock 0 allocations, and editor layout at all three
  sizes. Linux VST3 linked. juceaide needed libfontconfig-dev.
- **macOS**: AppleClang Release at 0.1.0 (`39c71493`) passed 12/12 and LoadCheck. 0.1.1 is
  header-meter padding/width and a roomier Variation button so the installed build is
  distinguishable.
- **Known limits / not yet checked**: Ableton Live (MIDI out, drag MIDI/WAV, host transport,
  song position). Windows VST3. Installer packaging of a real zip (make-release.py lists
  the plugin; no release was cut).
