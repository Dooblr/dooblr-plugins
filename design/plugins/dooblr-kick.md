## Notes (hand-written)

- Suite-wide rules: `design/dooblr-design-system.md` (sections 1-10 and 12).
- `dooblr-kick/README.md`
- **Time Scale (`menv_tscale`, host name "Time Scale", 0.25x..4.00x, default 1.00x):**
  automatable Ableton VST parameter. Multiplies every Master Env point time in the DSP
  (`applyMasterMacros`); stored `menv{N}_time` values stay editable. Those point times are
  the delay / sustain / release (and attack / hold) stages of the drawn master envelope.
  UI knob is 2× diameter (0.3.7); readout shows `1.00x` (0.3.8).
