## Notes (hand-written)

- Suite-wide rules: `design/dooblr-design-system.md` (sections 1–10). Layout is a one-page
  hardware-style board (CTRL / OSCILLATOR / TIMBRE / SLOPE / CONTOUR / DYNAMICS, virtual
  patch jacks), drawn with the existing palette only. No new colour, font, radius or alpha tokens.
- `dooblr-0coast/README.md`
- This is an **independently designed approximation** of the Make Noise 0-Coast "no-coast"
  architecture, from the published 0-Coast manual. It is not a circuit-level emulation and
  does not use third-party code, artwork or trademarks on the UI.
- **Normals** (switching jacks): Slope CV → Multiply CV; MIDI A Gate → Contour Gate;
  Oscillator Triangle → Balance Ext; Contour CV → Dynamics CV; MATH CH2 unpatched is the
  attenuverter offset. Patching a cable to the input overrides the normal. Cables are state,
  not parameters; drag output → input, double-click a cable to remove it.
- **Linear FM** is not normalled (the manual has you patch Slope or Contour). The Lin FM
  knob is an attenuator on that input.
- **Level** is clean to about 80%, then overloads, matching the manual's line output.
- **Clock** follows the host tempo (120 BPM if the playhead is missing). A simple MIDI
  arpeggiator (traditional held-order, or Latch & Shift) runs at that clock. The first
  held note sounds immediately; later steps follow the clock.
- **Vari-Response** on Slope and Contour: logarithmic (CCW) stretches the programmed
  Rise/Fall/Onset/Decay times, linear (noon) matches them, exponential (CW) compresses
  them. Time knobs snap on the first audio tick after prepare so panel times match, then
  smooth to avoid zipper noise.
- **Legato off** retriggers Contour on every new MIDI note (including overlap); legato on
  holds the gate and does not restart the envelope.
- **Multiply** pre-gains into the ADAA folder, so the Slope→Multiply CV normal is audible
  as cyclic AM as well as extra folds.
- **Omitted** (see README): hardware calibration, PGM-page button choreography (those
  settings are parameters), MIDI learn / SysEx / CC page programming, Eurorack-level
  extra outputs, clock-synced portamento CCs.
